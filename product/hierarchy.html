Role Hierarchy & Scoped Authority Matrix

Explicit separation of duties. Clear rights from platform superusers down to individual contributors.

ROLE SCOPE ADMINISTRATIVE RIGHTS & CAPABILITIES
PLATFORM ADMIN Global Platform Superuser over SaaS infrastructure, global tenant provisioning, and billing enforcement.
ORGANIZATION OWNER Whole Organization Full sovereignty over organization profile, department creation, billing, Clerk SSO, and audit exports.
ORGANIZATION ADMIN Whole Organization Member invitation, team assignment, board creation, and department oversight without billing rights.
DEPARTMENT MANAGER Specific Department Scoped manager: Creates sub-teams, assigns Team Leads, oversees departmental sprint velocity and channels.
TEAM LEAD Specific Team Pod Pod leader: Sets sprint goals, configures Kanban columns and WIP limits, assigns tasks, moderates channels.
TEAM MEMBER Assigned Pods Standard contributor: Creates and moves tasks, posts in assigned team channels, comments and attaches files.

Tenant Isolation via PostgreSQL Row Level Security (RLS)

CrossTech uses a shared-database, shared-schema, strict-tenant-scoping architecture. Every operational table (departments, teams, boards, tasks, channels, messages, audit_logs) includes a mandatory organization_id foreign key.

// Supabase PostgreSQL Row Level Security Policy
CREATE POLICY tenant_isolation_policy ON tasks FOR ALL USING (
  organization_id IN (
    SELECT organization_id FROM organization_memberships
    WHERE user_id = auth.uid() AND status = 'ACTIVE'
  )
);
🛡️
Zero-Leak Guarantee:

Cross-tenant data contamination is physically impossible at the database engine level. Even if an attacker attempts raw API parameter tampering, PostgreSQL drops unauthorized queries automatically before execution.
